Vercel mein backend project ke environment variables mein 

AUTOMATION_MAX_COMMENTS_PER_HOUR=0 aur 
AUTOMATION_MAX_DMS_PER_HOUR=0 

set karo.

Ye cap ek post par nahi lagta, poore account par lagta hai. Sab posts ke replies milke ek hi ghante ke counter mein ginte hain. 
Aapke 500 comments/ghanta ke case mein default 150/200 sach mein 350 se zyada replies aur 300 DMs rok deta, aur wo “failed” ban jaate. 
Ye default maine andaze se rakha tha aur galat tha.


Delay ke baare mein: reply aur DM ke beech ka 0.8–2.5 second ka pause abhi bhi on hai. 
500 comments/ghanta ke hisaab se ye theek hona chahiye, kyunki har webhook alag chalta hai. 
Phir bhi, agar bahut saare comments ek saath aayein aur webhook slow lage, to 

AUTOMATION_DELAY_MAX_MS=0 


set karke pause band kar do.



Token alert + expiry: token fail hote hi Telegram, email ya webhook par message jata hai (6 ghante mein ek). Settings mein token ki asli expiry date dikhti hai, aur 7 din bachne par warning banner aata hai.
Retry failed: Logs page ke upar panel hai. Ek click mein ek baar mein 15 comments tak dobara bhej sakte ho.
Deleted job warning: Dashboard par banner, Post Mapping mein “Job removed” badge, aur alert message.
Click tracking: Analytics mein clicks, click rate aur per-post/per-link breakdown. Ye tabhi chalega jab TRACKING_BASE_URL set karoge, nahi to links pehle jaise seedhe jayenge.
Test a comment: Rules page ka button hai, jo bina kuch bheje dikhata hai ki kaunsa rule match hua aur reply/DM kaisa dikhega.
Unmatched comments: Rules page par common words ke chips aate hain, ek click mein naya rule ban jata hai.
Hourly cap + delay: Reply aur DM ke beech 0.8–2.5 second ka random pause, aur ghante ki limit.
Reply variations: Rule mein extra comment templates, har reply ke liye random ek chuna jata hai.
Rule schedule: Start aur end date, aur rule card par “Ends 20 Oct” jaisa badge.
Daily summary: Raat ko ek message aata hai, jisme “needs attention” list bhi hoti hai.

Auth ka jawab: /api/automation/* pe Firebase login aur admin check pehle se laga hai, to bina login ke koi rules ya mappings nahi badal sakta.
