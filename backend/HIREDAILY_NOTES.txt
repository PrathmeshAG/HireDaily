3) ENVIRONMENT VARIABLES  (Vercel > backend project > Settings > Env Vars)
--------------------------------------------------------------------------
Pehle se zaroori (backend/src/config/env.ts mein poori list):
  META_ACCESS_TOKEN, INSTAGRAM_BUSINESS_ID, META_APP_ID, META_APP_SECRET,
  META_DRY_RUN (true = kuch asli nahi bhejta, sirf test)

Naye, sab OPTIONAL (set nahi karoge to purana behaviour):
  TRACKING_BASE_URL   backend ka public URL, jaise https://hiredaily-backend.vercel.app
                      (ye set hai: Settings mein "Link click tracking: On")
  CRON_SECRET         lamba random text. Scheduled checks ke liye.
  TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID           Telegram alerts
  RESEND_API_KEY, ALERT_EMAIL_TO, ALERT_EMAIL_FROM   Email alerts
  ALERT_WEBHOOK_URL                              Slack/Discord alerts
  AUTOMATION_MAX_COMMENTS_PER_HOUR   0/khali = limit nahi (poore account par, sab posts milke)
  AUTOMATION_MAX_DMS_PER_HOUR        0/khali = limit nahi
  AUTOMATION_DELAY_MIN_MS, AUTOMATION_DELAY_MAX_MS   reply aur DM ke beech random pause
                      MAX = 0 karo to pause band. (Default 800 - 2500 ms)
Env change ke baad backend REDEPLOY zaroori hai.

5) KUCH GADBAD HO TO
--------------------------------------------------------------------------
Settings mein "Disconnected" / Replies nahi ja rahe:
  1. Vercel > hiredaily-backend > Logs mein "Comment reply failed" dhundo.
  2. "Session has expired" / "Error validating access token" = token expire.
     Naya token lagao (upar step), phir Logs > Retry failed.
  3. Dashboard/Settings ka message dekho (token invalid, job deleted...).
Reply gaya par DM nahi: Logs mein DM error dekho; follow gate ka status dekho.
Rule match nahi ho raha: Rules > "Test a comment" chalao, wo bata dega kyun.
Template se reply nahi ja raha: kisi variable (company/location) ki value khali hogi.
  Khali variable par app reply BHEJTA HI NAHI (ye original behaviour hai).
  Job ke bina mapping mein company="the company", location="Online" aata hai.
DM mein button nahi dikha: Meta ne structured message reject kiya hoga; plain
  text list chali jaati hai (fallback). Logs mein check karo.
Click count nahi badh raha: TRACKING_BASE_URL sahi hai? DM ka button tap karke dekho.
Vercel log mein 429 / rate limit: API ka rate limit 120 requests / 15 min.
Test chalane: backend folder mein "npx tsx test/update4.test.ts" (aur multi-link,
  post-mapping, instagram, automation-final).
  PURANE FAIL TESTS (mere changes se pehle ke): rule-engine 2, instagram-dm 11,
  env-validation 1. Inhe ignore mat karna, kabhi theek karna.


6) FOLLOW STATUS KA MATLAB (Users page)
--------------------------------------------------------------------------
Follower      = Instagram ne confirm kiya ki wo follow karta hai. Link turant mila.
Not following = Instagram ke hisaab se follow nahi karta. Pehle follow karne bola,
                confirm karne ke baad link bheja.
Unknown       = Jawab nahi mila. Ya to kabhi check hi nahi hua (comment-only rule
                follow gate nahi chalata, purane users), ya Instagram us account ke
                liye bata nahi paya. "Follow nahi karta" ka matlab NAHI hai.
Ye har user ka SABSE LATEST follow-check result hai.


7) VERCEL.JSON KYA HAI (aur kyun chahiye)
--------------------------------------------------------------------------
vercel.json = Vercel ke liye ek settings file (project folder mein).
Usme aap Vercel ko batate ho: kaunsa URL kab apne aap chalana hai ("crons"),
redirects, headers etc.
Humne sirf cron ke liye banaya hai: roz raat 9 baje (IST) /api/cron/daily
chale -> token check + deleted jobs check + daily summary message.
Abhi ACTIVE NAHI hai: file ka naam backend/vercel.cron.example.json hai.
Jab alerts on karo: usse "vercel.json" naam do, redeploy. (Vercel Hobby plan par
cron din mein sirf ek baar chalta hai.) Alerts ke bina iska fayda nahi,
isliye abhi mat lagao. Naya file hone se build mein koi dikkat aaye to hata do.
Alternative: cron-job.org (free) se URL call karwao.
